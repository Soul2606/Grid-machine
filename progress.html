Circuits

Each circuit type: Logic circuit, Processor, Computer... corresponds to each tech tier: Basic, Solid, Advanced...

Down the table is each circuit tech level, the circuit type does not change with tech level, but the cost and complexity changes. Generally the higher tech circuits are cheaper but require more advanced technology to assemble.

Tiers

Each tier comes with increasing speed and capabilities, but also an exponential increase in power consumption.
