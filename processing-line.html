Error message meaning

No_recipe
The following machine has no recipes that can consume any items provided from the previous machine.
Ambiguous
Multiple recipes can consume the same items or there is an overlapping set of items being consumed.
No_outputs
If you get this message then there might be a broken recipe. This message is an actual error and should be reported.
